# 📝 Full Stack To-Do List App

A simple and interactive Full Stack To-Do List application built using **HTML, CSS, JavaScript, Node.js, Express, and MySQL**.

---

## 🚀 Features

- ➕ Add new tasks (name + description)
- 📋 View all tasks from database
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Data stored in MySQL database
- 🎨 Modern and responsive UI with animations

---

## 🛠️ Tech Stack

### Frontend:
- HTML
- CSS (Modern UI + Animations)
- JavaScript (Fetch API)

### Backend:
- Node.js
- Express.js

### Database:
- MySQL
